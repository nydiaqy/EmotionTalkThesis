Group conversational partners

Grouping based on Bronfenbrenner’s ecological systems

Group 1: Mother (MOT)

Group 2: Father (FAT)

Group 3: Adult with existing relationship (ADT): Teacher,Grandmother, Relative,Grandfather, Caretaker, Target_Adult

Group 4: Siblings (SIB): Sister, Brother,Sibling

Group 5: Other children (OTH_C): Child, Friend, Playmate, Boy, Girl, Student

Group 6: Other adults (OTH_A) : Investigator, Participants, Adult,Unidentified, Other, Media, Visitor, Environment,Male, Female, Group, Doctor, Uncertain

Child age distribution

Age distribution across transcripts, and count of participants with missing age information.

# Age distribution at the transcript level
age_dist <- ut_eng_na %>%
  distinct(transcript_id, target_child_id, target_child_age) %>%
  summarise(
    n_transcripts    = n(),
    n_children       = n_distinct(target_child_id),
    missing_age_tr   = sum(is.na(target_child_age)),
    pct_missing_age  = round(mean(is.na(target_child_age)) * 100, 1),
    mean_age         = round(mean(target_child_age, na.rm = TRUE), 2),
    sd_age           = round(sd(target_child_age,   na.rm = TRUE), 2),
    min_age          = round(min(target_child_age,  na.rm = TRUE), 2),
    max_age          = round(max(target_child_age,  na.rm = TRUE), 2)
  )
print(age_dist)

Conversational partner categories per transcript

Number of transcripts with Target Child + exactly 1 partner category vs. more than 1 (using the processed emotion dataset)

utt_pe <- readRDS(here("01Data", "02Derived", "utt_partners_emotions.rds"))

partner_category_counts <- utt_pe %>%
  filter(speaker_code != "CHI") %>%           # count partner categories only
  group_by(transcript_id) %>%
  summarise(
    n_partner_categories = n_distinct(role_category, na.rm = TRUE),
    .groups = "drop"
  )

partner_summary <- partner_category_counts %>%
  mutate(partner_group = ifelse(
    n_partner_categories == 1,
    "Target Child + 1 partner category",
    "Target Child + >1 partner categories"
  )) %>%
  count(partner_group, name = "n_transcripts") %>%
  mutate(pct = round(n_transcripts / sum(n_transcripts) * 100, 1))

print(partner_summary)
