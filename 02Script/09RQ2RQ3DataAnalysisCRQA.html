09 – RQ2 & RQ3: Windowed Cross-Recurrence Analysis

Overview

RQ2 – Do emotion words co-occur across conversational turns (child ↔︎ partner)? RQ3 – Is there a directional influence in emotion word use between child and partner?

Method: Windowed Cross-Recurrence Rate (wRR)

We build a cross-recurrence plot (CRP) for each transcript — an N×N binary matrix where cell (i, j) = 1 if child’s i-th turn and partner’s j-th turn both contain ≥1 emotion word, and 0 otherwise. Only (1,1) entries are marked as recurrent: matching zeros (both speakers silent) carry no information about emotional coupling.

We restrict attention to a diagonal band of width ±W around the main diagonal (all cells where |i−j| ≤ W). This band captures lagged co-occurrence up to W turns away, while excluding distant, temporally irrelevant pairings.

Windowed Recurrence Rate (wRR) = recurrent points in band / total cells in band.

Directionality — above vs. below the diagonal carries directional meaning:

  • lag L = j − i > 0 (above diagonal): child uses emotion at turn i, partner at later turn j → child leads
  • lag L = j − i <= 0 (below diagonal): partner speaks first → partner leads

Asymmetry index = RR at positive lags − RR at negative lags (positive = child leads).

Window size W is chosen from the data’s own inter-event interval (IEI) distribution (see Section 5).

5. Choose window size W from inter-event intervals

Because emotion words are rare, the window W should reflect the typical spacing between emotional expressions — not the duration of an emotion episode. If coupling exists, a partner’s responsive emotion word should arrive within the next inter-event interval of the child’s signal (and vice versa). Setting W to the median IEI ensures the diagonal band is wide enough to capture most genuine coupled pairs, without extending so far that random co-occurrence dominates.

An inter-event interval (IEI) is the gap in turns between two consecutive emotion words in the same series.

7. Cross-recurrence functions

We never build the full N×N matrix. Instead, we iterate over lags L from −W to +W and compute co-occurrence directly at each lag — equivalent to reading off each diagonal of the recurrence plot.

At lag L = j − i: - L ≥ 0: child[1:(N−L)] vs partner[(L+1):N] - L < 0: child[(|L|+1):N] vs partner[1:(N−|L|)]

# Co-occurrence count and cell count at a single lag
co_at_lag <- function(cs, ps, L) {
  N <- length(cs)
  if (L >= 0) {
    n_pairs <- N - L
    if (n_pairs <= 0) return(c(co = 0L, n = 0L))
    co <- sum(cs[1:n_pairs] == 1L & ps[(L + 1):N] == 1L)
  } else {
    aL      <- abs(L)
    n_pairs <- N - aL
    if (n_pairs <= 0) return(c(co = 0L, n = 0L))
    co <- sum(cs[(aL + 1):N] == 1L & ps[1:n_pairs] == 1L)
  }
  c(co = co, n = n_pairs)
}

# Full diagonal-band recurrence profile for lags -W..+W
recurrence_profile <- function(cs, ps, W) {
  N   <- min(length(cs), length(ps))
  cs  <- cs[1:N]; ps <- ps[1:N]
  lags <- seq(-W, W)
  map_dfr(lags, function(L) {
    r <- co_at_lag(cs, ps, L)
    tibble(lag = L, co = r["co"], n_cells = r["n"])
  })
}

# Summary metrics from profile
summarise_crqa <- function(profile) {
  # wRR: total recurrences in band / total cells in band
  wRR <- sum(profile$co) / sum(profile$n_cells)

  # Directionality: above diagonal = child leads (lag > 0)
  #                 at or below diagonal = partner leads (lag <= 0)
  # lag = 0 is partner-leading because partner always speaks first
  # within each aligned turn-pair (partner-first convention)
  pos <- profile %>% filter(lag > 0)
  neg <- profile %>% filter(lag <= 0)
  RR_pos <- sum(pos$co) / sum(pos$n_cells)
  RR_neg <- sum(neg$co) / sum(neg$n_cells)

  tibble(
    wRR        = wRR,
    RR_pos     = RR_pos,       # child leads
    RR_neg     = RR_neg,       # partner leads (includes lag 0)
    asymmetry  = RR_pos - RR_neg   # + = child leads, − = partner leads
  )
}

9. Shuffled baseline

Shuffle the child series to destroy temporal order while preserving its emission rate. Any remaining recurrence is due purely to base rates (both speakers happen to use emotion words at similar rates), not coupling. Subtracting this baseline removes the base-rate contribution from both wRR and asymmetry.

set.seed(42)

crqa_shuffled <- map_dfr(seq_len(nrow(crqa_series_f)), function(i) {
  cs_shuf <- sample(unlist(crqa_series_f$child_series[[i]]))
  ps      <- unlist(crqa_series_f$partner_series[[i]])
  na      <- crqa_series_f$n_aligned[i]

  prof <- recurrence_profile(cs_shuf[1:na], ps[1:na], W = WINDOW_W)
  summarise_crqa(prof) %>%
    rename(wRR_shuf = wRR, RR_pos_shuf = RR_pos,
           RR_neg_shuf = RR_neg, asymmetry_shuf = asymmetry) %>%
    mutate(transcript_id = crqa_series_f$transcript_id[i])
})

11a-ii. Age-block t-tests — does direction shift across development?

A non-significant overall test may mask a developmental reversal: child-leading at younger ages cancelling out partner-leading at older ages (or vice versa). We split the sample into 1-year age bins and run a one-sample t-test against μ = 0 within each bin. P-values are FDR-adjusted across blocks.

crqa_data_blocks <- crqa_data %>%
  filter(!is.na(target_child_age_yrs), !is.na(asymmetry)) %>%
  mutate(age_block = cut(
    target_child_age_yrs,
    breaks         = seq(floor(min(target_child_age_yrs)),
                         ceiling(max(target_child_age_yrs)),
                         by = 1),
    include.lowest = TRUE,
    right          = FALSE
  ))

block_tests <- crqa_data_blocks %>%
  group_by(age_block) %>%
  filter(n() >= 10) %>%          # require at least 10 transcripts per block
  summarise(
    n         = n(),
    mean_asym = mean(asymmetry_corrected),
    se_asym   = sd(asymmetry_corrected) / sqrt(n()),
    t_stat    = t.test(asymmetry_corrected, mu = 0)$statistic,
    df        = t.test(asymmetry_corrected, mu = 0)$parameter,
    p_value   = t.test(asymmetry_corrected, mu = 0)$p.value,
    ci_low    = t.test(asymmetry_corrected, mu = 0)$conf.int[1],
    ci_high   = t.test(asymmetry_corrected, mu = 0)$conf.int[2],
    .groups   = "drop"
  ) %>%
  mutate(
    p_adj = p.adjust(p_value, method = "fdr"),
    sig   = case_when(
      p_adj < 0.001 ~ "***",
      p_adj < 0.01  ~ "**",
      p_adj < 0.05  ~ "*",

  )
