10 – Additional Analysis: Partner Emotion Word Use as Predictor of Child Emotion Word Use

Overview

Research question — If social partners talk more about emotion, do children talk more about emotion too? And does this association change across development?

This analysis operates at the transcript level (one observation per transcript), complementing the turn-by-turn CRQA approach in script 09.

Two sections are reported:

Part 1 — Full sample: All transcripts retained. All non-child speakers collapsed into one “partner” category. Tests the overall partner → child association and its developmental moderation and mediation.

Part 2 — Partner-type comparison: Restricted to transcripts where the child speaks to exactly one partner type. Tests whether the partner → child association differs by who the child is talking to (Mother, Father, Sibling, etc.).

3. Aggregate all transcripts — partner as single category

All non-child utterances are summed into one “partner” series per transcript, regardless of who is speaking.

speaker_summary_all <- utt %>%
  mutate(speaker_category = if_else(role_category == "Target Child",
                                    "child", "partner")) %>%
  group_by(transcript_id, speaker_category) %>%
  summarise(
    total_tokens  = sum(num_tokens,    na.rm = TRUE),
    total_emotion = sum(emotion_count, na.rm = TRUE),
    n_utterances  = n(),
    .groups = "drop"
  ) %>%
  mutate(emo_rate = if_else(total_tokens > 0,
                             total_emotion / total_tokens, NA_real_))

transcript_all <- speaker_summary_all %>%
  pivot_wider(
    id_cols     = transcript_id,
    names_from  = speaker_category,
    values_from = c(emo_rate, total_tokens, total_emotion, n_utterances)
  ) %>%
  rename(
    child_emo_rate   = emo_rate_child,
    partner_emo_rate = emo_rate_partner,
    child_tokens     = total_tokens_child,
    partner_tokens   = total_tokens_partner,
    child_emotion    = total_emotion_child,
    partner_emotion  = total_emotion_partner,
    child_utts       = n_utterances_child,
    partner_utts     = n_utterances_partner
  ) %>%
  left_join(age_lookup, by = "transcript_id") %>%
  mutate(target_child_age_yrs = target_child_age / 12) %>%
  filter(
    !is.na(child_emo_rate),
    !is.na(partner_emo_rate),
    !is.na(target_child_age_yrs),
    child_tokens   >= 10,
    partner_tokens >= 10
  )

transcript_dyadic <- speaker_summary_dyadic %>%
  pivot_wider(
    id_cols     = c(transcript_id, partner_type),
    names_from  = speaker_category,
    values_from = c(emo_rate, total_tokens, total_emotion, n_utterances)
  ) %>%
  rename(
    child_emo_rate   = emo_rate_child,
    partner_emo_rate = emo_rate_partner,
    child_tokens     = total_tokens_child,
    partner_tokens   = total_tokens_partner,
    child_emotion    = total_emotion_child,
    partner_emotion  = total_emotion_partner,
    child_utts       = n_utterances_child,
    partner_utts     = n_utterances_partner
  ) %>%
  left_join(age_lookup, by = "transcript_id") %>%
  mutate(target_child_age_yrs = target_child_age / 12) %>%
  filter(
    !is.na(child_emo_rate),
    !is.na(partner_emo_rate),
    !is.na(target_child_age_yrs),
    child_tokens   >= 10,
    partner_tokens >= 10
  ) %>%
  mutate(
    partner_type = factor(partner_type),
    partner_type = relevel(partner_type, ref = "Mother")
  )
